# СВОЁ — первая обновлённая сборка

Загрузка в корень GitHub Pages: `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`.

Функции этой сборки: пять разделов навигации; два режима списка дел на сегодня; добровольная отметка энергии и настроения; быстрое и полное добавление задач; задачи без даты остаются в «Моих задачах»; календарный обзор; дневник и простая вечерняя сводка; локальное сохранение в браузере.

Важно: это ранний прототип. Разделы «Моя жизнь» пока являются каркасом. Данные этой версии хранятся локально в браузере. Удаление данных сайта или очистка хранилища браузера может их удалить. Резервное копирование, Face ID, полноценные повторения, уведомления и PDF-экспорт ещё не реализованы.
