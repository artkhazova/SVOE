# СВОЁ 3.0

Обновлённая сборка для GitHub Pages. Загрузить в корень репозитория все шесть файлов.

## Что нового
- Календарь: переключение месяцев, кнопка «Сегодня», выбор даты и список задач выбранного дня.
- Моя жизнь: рабочие локальные модули «Дом», «Здоровье и движение», «Привычки», «Мои челленджи» с добавлением, редактированием и удалением записей.
- Дневник: редактирование и удаление записей.
- Сохранение по-прежнему локальное в браузере на ключе `svoe_v2_state`, чтобы сохранить данные предыдущей версии.
- Service Worker обновлён до `svoe-v3-cache-1`.

## Важно
Это локальная версия-прототип. Данные остаются в браузере этого устройства. Перед очисткой данных сайта или переустановкой браузера сделайте отдельную резервную копию вручную; встроенный экспорт/облачная синхронизация пока не реализованы.
