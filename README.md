# СВОЁ — стартовый PWA-проект

Это первая техническая заготовка устанавливаемой веб-версии приложения.

## Что уже работает
- выбор физического ресурса и эмоционального состояния;
- добавление и отметка задач;
- сохранение задач, выбора состояния и заметки дневника в localStorage;
- базовая навигация по разделам;
- PWA-манифест и service worker для офлайн-кэша.

## Важно
Это ранний прототип, а не готовый продукт. Данные пока хранятся локально в браузере на этом устройстве. Нет облачной синхронизации, резервного копирования, уведомлений и полноценной логики адаптации нагрузки.

## Как установить на iPhone
1. Разместить содержимое папки на HTTPS-хостинге.
2. Открыть опубликованный адрес именно в Safari.
3. Нажать «Поделиться» → «На экран Домой».
4. Включить «Открывать как веб-приложение», если этот переключатель доступен, затем нажать «Добавить».

## Следующие этапы
1. Доработать дизайн по утверждённому образу: олива, бургунди, охра, айвори; знак с солнцем.
2. Реализовать календарь, категории задач, приоритеты и гибкое расписание.
3. Реализовать правила адаптации плана по ресурсу.
4. Добавить привычки, челленджи, дневник и резервное копирование.
5. При необходимости перенести интерфейс в React Native / Expo и собирать iOS в облаке.
